## New artwork twins and rollback

The native packages carry the MIT-licensed public PNGs from Fedora #52, with immutable origin and per-file SHA256 in `provenance.json`. Both install the ten hicolor sizes, `start-here` aliases and `system-logo-white.png`; Plasma About uses the native distribution name and logo path. Arch installs the package in every image. NixOS exposes it through the overlay and system profile, with declarative XDG configuration. Desktop image checks reject missing launcher icons or invalid PNG signatures and follow Nix store links inside the image.

Arch rollback removes `aurora-logos` and restores any administrator-owned XDG configuration using normal pacman backup handling. NixOS rollback selects the previous generation; immutable logo paths and XDG configuration revert together. No package publication, image/channel promotion or device modification is part of these PRs.
